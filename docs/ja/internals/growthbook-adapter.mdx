## 概要

Claude Code の GrowthBook システムは、環境変数によるカスタム GrowthBook サーバーへの接続と、feature flag のリモート制御をサポートしています。

- **設定がある場合**: GrowthBook インスタンスに接続し、feature 値を取得してキャッシュする
- **設定がない場合**: すべての feature 読み取りでコード内のデフォルト値を直接返し、ネットワークリクエストは一切発生しない

## 環境変数

| 変数 | 必須 | 説明 |
|---|---|---|
| `CLAUDE_GB_ADAPTER_URL` | はい | GrowthBook API のアドレス。例: `https://gb.example.com/` |
| `CLAUDE_GB_ADAPTER_KEY` | はい | GrowthBook SDK Client Key。例: `sdk-xxxxx` |

両方の変数を設定した場合にアダプタモードが有効になります。それ以外の場合は GrowthBook を完全にスキップします。

## 使用方法

### 基本的な使い方

```bash
CLAUDE_GB_ADAPTER_URL=https://gb.example.com/ \
CLAUDE_GB_ADAPTER_KEY=sdk-abc123 \
bun run dev
```

### GrowthBook を使わない場合（デフォルトの動作）

```bash
bun run dev
# すべての getFeatureValue_CACHED_MAY_BE_STALE("xxx", defaultValue) は defaultValue を直接返す
```

## GrowthBook サーバー側の設定

### 手順

1. **GrowthBook サーバーをデプロイする**（Docker によるセルフホスト、または Cloud 版）
2. **Environment を作成する**（例: `production`）
3. **SDK Connection を作成し**、SDK Key（`CLAUDE_GB_ADAPTER_KEY`）を取得する
4. **必要な Feature を追加する**。key と型は以下の一覧を参照

### 中核原則

- **feature を 1 つも設定しなくても正常に動作します**。コード内のすべての呼び出しでデフォルト値を指定しているためです
- リモートで制御したい feature だけを作成し、それ以外にはコードのデフォルト値を使います
- GrowthBook に feature を設定すると、その値がコード内のデフォルト値を上書きします

## 値を解決する優先順位

各 feature の値は次の順序で解決され、最初に一致した値が返されます。

```
1. CLAUDE_INTERNAL_FC_OVERRIDES 環境変数（JSON オブジェクトによるオーバーライド）
   ↓ 一致なし
2. growthBookOverrides 設定（~/.occ.json、ant ビルドのみ）
   ↓ 一致なし
3. メモリキャッシュ（remoteEvalFeatureValues、このプロセスがサーバーから取得）
   ↓ 一致なし
4. ディスクキャッシュ（~/.occ.json の cachedGrowthBookFeatures）
   ↓ 一致なし
5. コード内の defaultValue 引数
```

## キャッシュと更新の仕組み

| 仕組み | 説明 |
|---|---|
| **ディスクキャッシュ** | `~/.occ.json` の `cachedGrowthBookFeatures` フィールド。プロセスをまたいで永続化 |
| **定期更新** | 6 時間ごとにサーバーから最新値を自動取得（`setInterval` + `unref`） |
| **初期化タイムアウト** | 初回接続は 5 秒でタイムアウトし、その後はディスクキャッシュまたはデフォルト値を使用 |
| **Auth の変更** | ログイン / ログアウト時にクライアントを自動的に破棄して再作成 |

## 実装の詳細

2 ファイルの計 3 か所を変更しています。

1. **`src/constants/keys.ts`** — `getGrowthBookClientKey()` は `CLAUDE_GB_ADAPTER_KEY` を優先的に読み取る
2. **`src/services/analytics/growthbook.ts`** — アダプタモードでは `isGrowthBookEnabled()` を直接有効化する
3. **`src/services/analytics/growthbook.ts`** — base URL には `CLAUDE_GB_ADAPTER_URL` を優先的に使用する

130 個以上ある呼び出し元ファイルを変更する必要はありません。
